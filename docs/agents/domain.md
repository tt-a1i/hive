# Domain Docs

Hive is a single-context repository. The root [CONTEXT.md](../../CONTEXT.md)
already defines its vocabulary. Read it before changing domain terms or describing
collaboration behavior. Use its terms in code, issues, plans, and review findings.

Read [design decisions](../design-decisions.md) for architectural boundaries.
Read relevant records under `docs/adr/` if that directory exists; create records
only when a real decision needs one. Missing ADR files do not block ordinary work.

When a proposed change conflicts with an existing definition or decision, state
the conflict and resolve it explicitly. Record new terms in `CONTEXT.md` and new
architectural decisions in the appropriate decision document rather than keeping
parallel glossaries or unrelated multi-context templates.
